## Анализатор страниц (Python Flask)
- Это сайт, который анализирует указанные страницы на SEO-пригодность по аналогии с [PageSpeed Insights](https://pagespeed.web.dev/). Пользователь добавляет адреса сайтов, запускает проверку и видит её результаты, сохранённые в базе данных.
- Это полноценное веб-приложение на фреймворке Flask. Здесь отрабатываются базовые принципы построения современных сайтов на MVC-архитектуре: роутинг, обработчики запросов, шаблонизатор и взаимодействие с базой данных.
- Проект включает создание базы данных (нормальные формы, связи между сущностями), выполнение SQL-запросов через библиотеку psycopg, оформление интерфейса на Tailwind CSS и развертывание локального окружения (веб-сервер, база данных, понимание TCP/IP, портов). В финале — деплой в продакшен на PaaS-хостинге render.com.

- [x] Для сборки проекта добавьте команду:
```bash
install:

```
Для старта проекта добавьте такую команду:
```bash
dev:
    uv run flask --debug --app page_analyzer:app run
```
- [x] Используйте эту команду, что запускать приложение в режиме отладки в процессе разработки.

- [x] Установите wsgi-сервер gunicorn и добавьте команду для запуска в продакшене:
```bash
PORT ?= 8000
start:
    uv run gunicorn -w 5 -b 0.0.0.0:$(PORT) page_analyzer:app
```
Эта команда запускает приложение уже в режиме продакшена. Приложение будет доступно по адресу http://localhost:8000, если в переменных окружения не указан порт, необходимый для деплоя.
- [x] Для деплоя мы будем использовать PAAS-сервис render.com. Чтобы развернуть на подобных сервисах приложение, нужно лишь указать ссылку на репозиторий, а также команды сборки и запуска. Заведите аккаунт на render.com и создайте приложение (web service). Перед сборкой проекта нам нужно установить пакетный менеджер на платформу. Для этого мы напишем небольшой build.sh скрипт:
```bash
#!/usr/bin/env bash
```
# скачиваем uv и запускаем команду установки зависимостей
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
source $HOME/.local/bin/env
make install
```
Сделайте скрипт исполняемым (chmod +x ./build.sh) и добавьте такую команду в Makefile:
```bash
build:
    ./build.sh
```
- [x] В настройках сервиса укажите команду сборки приложения — make build. Также на render.com все зависмости проекта ставятся глобально, потому добавим новую команду запуска приложения — make render-start
```bash
render-start:
    gunicorn -w 5 -b 0.0.0.0:$(PORT) page_analyzer:app
```
